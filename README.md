# Notebook

Notebook is a Kotlin Multiplatform notes app for Android and iOS. It uses Clean Architecture and MVVM, with shared Kotlin code across platforms.

## Features

- Create, edit, and delete notes.
- Choose colour contrast options to improve readability.
- Use Android dynamic colours for a more personalised interface.

## Built with

- Kotlin Multiplatform and Compose Multiplatform
- SQLDelight for local note storage
- DataStore for preferences
- Koin for dependency injection
- Compose Navigation
- Kotlin Serialization and Coroutines
- Material 3

## Build from source

Clone this repository:

```bash
git clone https://github.com/prashant17d97/Notebook-KMP.git
cd Notebook-KMP
```

Open the project in Android Studio to build and run the Android app. For iOS, open the iOS project in Xcode. Make sure the required Android and iOS development tools are installed.
